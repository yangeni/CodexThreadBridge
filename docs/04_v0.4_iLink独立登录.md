# CodexThreadBridge v0.4 iLink 独立登录说明

本说明对应 v0.4：CodexThreadBridge 不安装、不启动、不依赖 OpenClaw 本体。OpenClaw-WeChat 和其他开源 iLink 客户端只作为协议参考；实际运行由本仓库自己的 Python 登录 helper 和现有 OpeniLink runtime 完成。

v0.4 只解决一个缺口：

```text
扫码登录拿 iLink token
-> 保存本地凭据
-> runtime 从凭据文件读取 base_url/token
-> 复用 v0.3 getupdates/sendmessage 私聊文本链路
```

不在 v0.4 处理：

- 群聊 runtime。
- 媒体上传和文件回传。
- token 自动刷新。
- Windows 打包。
- OpenClaw 插件安装或 OpenClaw gateway。

## 准备 `.env`

从仓库根目录复制模板：

```bash
cp .env.example .env
```

推荐配置方式：

```text
CTB_PROJECT_ROOT=/Users/clngs/Documents/CLngs_Vault/CodexThreadBridge
ILINK_CREDENTIALS_PATH=data/local/ilink_credentials.json
ILINK_OWNER_USER_IDS=<扫码后识别出的 owner sender id>
ILINK_POLL_TIMEOUT_SECONDS=35
ILINK_REQUEST_TIMEOUT_SECONDS=30
CTB_CONTROLLER_COMMAND=/usr/bin/env,PYTHONPATH=/Users/clngs/Documents/Codex/tools/cross-thread-controller/src,CROSS_THREAD_CONTROLLER_DB=/Users/clngs/.codex/cross-thread-controller/state.sqlite3,python3,-m,cross_thread_controller.mcp_server
```

`ILINK_BASE_URL` 和 `ILINK_BOT_TOKEN` 仍可作为直接配置方式，但不推荐写入 `.env`。v0.4 推荐把 token 放在 `data/local/ilink_credentials.json`，该目录已被 `.gitignore` 排除。

## 扫码登录

在仓库根目录运行：

```bash
PYTHONPATH=src python3 -m codex_thread_bridge.adapters.ilink_auth login
```

helper 会打印一个二维码 URL。用微信打开或扫码确认后，凭据会保存到：

```text
data/local/ilink_credentials.json
```

helper 不会把 token 打印到终端。凭据文件权限会设置为 `0600`。

如果需要指定位置：

```bash
PYTHONPATH=src python3 -m codex_thread_bridge.adapters.ilink_auth login --credentials-path data/local/ilink_credentials.json
```

## 获取 owner sender id

第一次登录后，还需要知道你的微信 sender id，填入 `ILINK_OWNER_USER_IDS`。最小流程：

1. 用微信私聊 ClawBot 发一条普通消息，例如 `whoami`。
2. 运行只读诊断命令：

```bash
PYTHONPATH=src python3 -m codex_thread_bridge.adapters.ilink_auth probe-updates
```

3. 从输出里找到这条私聊消息对应的 `from_user_id`。
4. 把真实 `from_user_id` 写回 `.env` 的 `ILINK_OWNER_USER_IDS`。

`probe-updates` 只读取一批 iLink update，不回复微信，也不触发 Codex。

当前 v0.4 不自动把任意发消息的人设成 owner，避免扫码后被错误会话接管。

## 启动 runtime

```bash
set -a
source .env
set +a
PYTHONPATH=src python3 -m codex_thread_bridge.adapters.openilink_runtime --once
```

常驻运行：

```bash
set -a
source .env
set +a
PYTHONPATH=src python3 -m codex_thread_bridge.adapters.openilink_runtime
```

runtime 会优先读取 `ILINK_BASE_URL` 和 `ILINK_BOT_TOKEN`。如果这两个变量没有都设置，就读取 `ILINK_CREDENTIALS_PATH` 指向的本地凭据文件。

## 安全边界

- OpenClaw 不作为运行时依赖。
- token 只存在本机 ignored 文件或本机 `.env`。
- 登录 helper 不打印 token。
- 微信轮询不是 Codex 心跳，不会主动向 Codex session 发“检查在线”消息。
- owner 白名单仍由 Gateway Core 执行。
- Codex 工具审批仍在 Codex App 内完成，微信侧不代理 approval confirmation。
